# Big Mart Sales Prediction

## Project Overview
Big Mart Sales Prediction is a Machine Learning Regression project that predicts item-level outlet sales.

## Objective
The objective of this project is to estimate Item_Outlet_Sales using product and outlet characteristics.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- Google Colab

## Methodology
1. Load the Big Mart sales dataset
2. Explore the data
3. Handle missing values
4. Encode categorical variables
5. Split data into training and testing sets
6. Train the XGBoost regression model
7. Evaluate the model
8. Generate predictions

## Project Files
- Big_Mart_Sales_Prediction(5).ipynb
- Project Presentation
- README.md

## How to Run
Open the notebook in Google Colab and run all cells.

If prompted, upload the `Train.csv` dataset.

## Conclusion
This project demonstrates an end-to-end machine learning workflow for predicting Big Mart sales.
